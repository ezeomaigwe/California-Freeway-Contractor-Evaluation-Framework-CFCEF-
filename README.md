# California-Freeway-Contractor-Evaluation-Framework-CFCEF-
## Analysis of California Freeway Contractor Evaluation Framework (CFCEF)
A 10-week graduate capstone consulting project proposing the California Freeway Contractor Evaluation Framework (CFCEF) — a performance-based alternative to Caltrans' current lowest-bid contractor selection model. The framework weighs price alongside schedule adherence, cost control, project management capability, quality, financial stability, and safety, aiming to reduce rework, delays, and taxpayer cost from underqualified low-bid contractors.
